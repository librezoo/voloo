# v0.7.2 — Hardware revision 0.2 support

Recognizes the device-reported hardware revision 0.2 while retaining support for
existing devices that report the legacy 3.0 identity. CLI, Web, HTTP and MCP display
the value actually read from the device.

This host is paired with firmware 3.2.0. That firmware requires hardware identity 0.2.
Devices still reporting 3.0 require a service migration before using this release's
firmware; do not change protection settings to force an ordinary update.
Updates and rollbacks to firmware that cannot read the device's hardware identity
are refused. Firmware and hardware revision numbers are independent.

```sh
npm install -g @librezoo/voloo@0.7.2
voloo info
```

Device operations retain UID, OFF, valid-measurement, lock, authentication, trial
confirmation and rollback checks. Idle-only background shutdown is unchanged.
