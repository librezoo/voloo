What it does

Power control,
built into your workflow

One USB-C cable. No special drivers.

voloo uses your operating system's built-in USB CDC driver. USB carries control signals; a separate DC supply powers your device. The guide covers serial-port permissions if you need them.

Know whether it worked

voloo checks the device after each command and reports the result. If it can't confirm what happened, it tells you to check the state before continuing.

Switch off. Then clear the charge.

Residual voltage can remain after switching OFF. discharge drains the remaining charge and confirms VOUT ≤ 1 V; cycle then waits and switches power back on, so you can repeat a cold start.

Use the tools you already know

Click a button in the dashboard, write a script with the CLI or local HTTP API, or connect your AI agent through MCP.

Control each device by name

Connect each voloo with its own USB cable. Assign a name such as bench-a and use it to find and control the same unit, even after unplugging and reconnecting it.

Locks, logs and diagnostics

Lock a device to block power and name changes until you unlock it. Logs show where each command came from and what happened; voloo doctor helps you troubleshoot USB connections, permissions and voltage readings.

Before you begin

What to check before you connect

Computer connection USB-C USB is for control; no special driver needed
DC input voltage 3.3–28 V DC Tested with a 3 A constant-current load
Discharge threshold ≤ 1 V Checked against VOUT; a timeout is reported
Supported systems macOS · Linux · Win CLI and web dashboard on all three

Operating voltage: 3.3–28 V DC · Maximum recommended current: 3 A

3 A maximum recommended current 28 V × 3 A ≈ 84 W

Current above 3 A can damage the hardware. Tested with a 3 A constant-current load. Power is voltage × current: 28 V at 3 A is 84 W. This is one operating point, not a general power rating. Keep current at or below 3 A even at lower voltages.

When a valid VIN reading exceeds 30.5 V, voloo switches the output OFF and latches overvoltage protection. Once a valid reading falls below 30.0 V, the latch clears automatically, but output stays OFF. To restore power, press and hold Switch On in the dashboard or send a new ON command. No separate reset command is needed. These protection thresholds do not extend the 3.3–28 V operating range.

The constant-current test does not establish support for arbitrary inrush or inductive backfeed. voloo does not regulate voltage, current or power. Set external supply limits. Active discharge removes residual charge after shutdown; it is not a continuous electronic load.

wiring notes

Two checks before power-on

Reversed polarity damages the hardware. Use one power supply for the device and a separate supply for the USB host computer. Never power both from the same adapter.

1 Verify supply polarity

  • Reversed polarity damages the hardware. Verify supply polarity, then turn the supply output OFF before wiring.
  • Follow the IN, OUT and + / − markings on your unit. IN connects to the supply; OUT connects to the device. Don't rely on left and right in an illustration.
  • The illustration uses red for + and black for −. Check actual polarity with a multimeter, then turn the supply OFF and follow the physical markings.

2 Use independent supplies

  • The device supply and USB host computer must use separate adapters or independent supplies. Different ports on one multiport adapter do not count as separate supplies.
  • The device must take power only from voloo OUT. Disconnect other power sources, including the device's USB, battery or debugger VCC / 3V3, while voloo controls its supply.
  • When connecting a debugger or USB serial adapter to the device, connect only GND and the required signal lines.

Correct wiring: Supply A → voloo IN / OUT → device. Independent supply B → USB host computer. The device takes power only from OUT, never from the computer's USB or another source at the same time.

How to use the spring terminals

The orange tabs release the wire clamps; they don't switch power. If any charge remains, discharge to ≤ 1 V first. Then disconnect the external supply and USB-C before handling wires.

1 · Strip 11 mm

Keep the strands together. Check that any pre-fitted wire end fits the terminal.

2 · Press the orange tab

Press and hold the matching orange tab toward the circuit board to open the clamp.

3 · Insert the wire

Keep holding the tab and fully insert the conductor into the adjacent round opening in the green terminal.

4 · Release and check

Release the tab and gently pull the wire to check it is secure. No bare copper should be exposed. The orange opening is not a wire entry.

To remove a wire, disconnect all power first. Hold the matching orange tab and gently pull the wire straight out. Don't force it. Illustrated quick start → · Download the two-page A4 guide

Get started

Start with voloo ls

Install Node.js 18 or newer, then install with npm. Run voloo ls to list devices, or use voloo demo to try the simulated dashboard. 

 # Node 18+ · Install or update to the latest version 
$ npm install -g @librezoo/voloo@latest
 # Already installed? After updating, restart the background process 
$ voloo daemon stop
$ voloo ls
 # Or run without installing 
$ npx @librezoo/voloo@latest ls
 # Explore the dashboard with simulated devices 
$ voloo demo

Permission error (EACCES) during install?

npm installs global packages into a system directory by default, which a normal account cannot write to. Do not add sudo. It leaves your npm cache owned by root and causes more problems later.

Option 1 (recommended): use a global folder in your home directory 

$ mkdir -p ~/.npm-global
$ npm config set prefix ~/.npm-global
$ echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc
$ source ~/.zshrc
$ npm install -g @librezoo/voloo@latest

If you use bash, replace ~/.zshrc with ~/.bashrc.

Option 2: install Node with a version manager

With nvm, fnm, Volta or Homebrew, the global folder belongs to your user, so this error does not occur.

Option 3: run it without installing 

$ npx @librezoo/voloo@latest ls

Already installed with sudo? 

$ sudo npm uninstall -g @librezoo/voloo
$ sudo chown -R $(id -u):$(id -g) ~/.npm

Then reinstall with option 1.

Installed but voloo is not found?

Run npm config get prefix and check that the bin folder in that directory is on your PATH. On Windows, reopen the terminal.
