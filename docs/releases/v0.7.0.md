# v0.7.0 — USB firmware updates

Host 0.7.0 pairs with firmware 3.1.0 for compatible USB-C Voloo Switch devices.

- CLI, dashboard and local API share managed updates, progress and A/B rollback.
- Online updating downloads the encrypted firmware paired with this host release.
- Device identity, version, OFF state and valid measurements are checked before confirmation.
- Local `.voloofw` files remain supported. Incompatible devices or packages are refused.

```sh
npm install -g @librezoo/voloo@0.7.0
voloo ls
voloo firmware status DEVICE_UID
voloo firmware update DEVICE_UID
```

Replace `DEVICE_UID` with the exact listed UID. Update only when the target is idle
OFF, measurements are valid and VOUT <= 1 V. Do not stop the daemon during updating.
Updating does not switch off, discharge or restore ON for you.

When replacing an already running older host, wait for all device operations to
finish, stop that old daemon once, then run the new `voloo ls` and verify
`voloo daemon status` reports 0.7.0.

See the [中文升级教程](https://github.com/librezoo/voloo/blob/v0.7.0/docs/firmware-updates.zh.md)
and [English update guide](https://github.com/librezoo/voloo/blob/v0.7.0/docs/firmware-updates.md).

The host release was built and installation-checked on five platforms. Physical
updating and rollback were tested on one macOS-connected X035 board. This does not
qualify other boards, loaded switching, Flash endurance or physical power cuts.
