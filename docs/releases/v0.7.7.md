# v0.7.7 — Update every connected Voloo

With several Voloo connected, `voloo firmware update` (no device) first lists each device that
will be updated and each one skipped with the reason (already up to date, locked, not idle OFF
with VOUT <= 1 V, needs a newer voloo), asks once in a terminal, then updates one device at a
time. `voloo firmware update --all` skips the question for scripts. A skipped or failed device
never stops the others; the exit code is 2 when any update failed, and `--json` reports each
device. With one Voloo connected the command behaves as before.

```sh
npm install -g @librezoo/voloo@0.7.7
voloo daemon stop
```

Validated on two real boards: mixed states (one on 3.2, one on 3.3), locked and powered-on
devices skipped, the confirmation prompt answered n and y, and the CLI regression on each board
with the other as isolation check. Not covered: a mid-batch failure on real hardware.
