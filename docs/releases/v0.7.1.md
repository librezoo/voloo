# v0.7.1 — Idle-only background shutdown

Adds authenticated `POST /v1/shutdown/idle` to the local API. It returns 409 while
any device request is queued or running, including a cycle waiting between OFF
and ON. Client disconnects do not hide accepted operations. Once idle shutdown
is accepted, new device requests are refused before the process exits normally.
Existing unconditional shutdown behavior is unchanged; shutting down leaves device outputs unchanged.

```sh
npm install -g @librezoo/voloo@0.7.1
```

When replacing an already running older host, wait for device operations to finish,
stop the old background process once, then use the new host. This release uses the
same paired encrypted firmware 3.1.0 package as 0.7.0; it does not require reflashing.

Regression includes simulated queued/running work, caller disconnects, concurrent
job admission, authenticated HTTP refusal during cycle wait, and successful idle
shutdown after completion. No hardware power action was needed for this change.
