# v0.7.6 — Quiet update hints

The background process reads the public firmware manifest at most once a day (cached, 8 s
timeout, failures silent, nothing about you or your devices is sent). In a terminal,
`voloo ls`, `status` and `info` then print one line, once per device and version, when newer
firmware exists for a connected device or when a newer voloo is published; a firmware that
needs a newer voloo is reported together with the upgrade command. JSON, MCP and piped output
only gain read-only fields (`firmware_update_available`, `firmware_update_needs_host`,
`host_update_available`); the dashboard shows the firmware version in the USB firmware panel.
Nothing is installed automatically. Turn it off with `check_updates = false` in `config.toml`
or `VOLOO_NO_UPDATE_CHECK=1`.

```sh
npm install -g @librezoo/voloo@0.7.6
voloo daemon stop
```
