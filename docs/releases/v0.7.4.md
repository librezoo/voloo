# v0.7.4 — Firmware manifest, stale-daemon handling

`voloo firmware update` no longer downloads the asset of its own host release. It reads
`https://voloo.librezoo.com/firmware/x035/manifest.json` (fallback: the repository copy),
selects the newest firmware for the device's hardware identity and this host, verifies
size and SHA-256, and refuses to install anything older than the running firmware. Future
firmware releases need only a manifest entry, not a new npm version. If no manifest can be
read, it falls back to the asset paired with this release.

A background process left over from another host version is now replaced on connect when
idle; when it is busy, the online firmware update refuses instead of installing an older package.

```sh
npm install -g @librezoo/voloo@0.7.4
voloo firmware update DEV
```
