# v0.8.0 — Shell Tab completion

Voloo now completes commands and options in Bash, Zsh, Fish and PowerShell.
After installing, run `voloo` or `voloo ls` in an interactive terminal, accept the
one-time setup prompt and open a new terminal. To enable it later, run
`voloo completions install`. See the [setup guide](../user-guide.md#开启-tab-补全)
for commands that enable completion in the current terminal.

- `voloo info ` completes online device nicknames and full UIDs.
- `voloo firmware update ` completes a device or `--all`. After a device, Tab
  completes a local firmware path, including paths with spaces.
- Repeated USB drops now surface a cable and connection hint in the CLI and
  dashboard.

```sh
npm install -g @librezoo/voloo@0.8.0
voloo daemon stop
voloo ls
```

This host release uses the existing encrypted X035 firmware 3.3 package.
