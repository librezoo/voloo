# v0.7.3 — Firmware 3.3.0

This host is paired with firmware 3.3.0: the same features and protocol as 3.2.0
in a smaller image (linker relaxation, about 1.4 KB more headroom per slot). The
host code itself is unchanged; the release exists so `voloo firmware update` downloads
the 3.3.0 package.

```sh
npm install -g @librezoo/voloo@0.7.3
voloo firmware status DEV
voloo firmware update DEV
```

Devices must report hardware identity 0.2, idle OFF with valid measurements and
VOUT <= 1 V. Updating does not switch the output on. After the update `voloo info DEV`
shows firmware 3.3; the previous image stays in the other slot for `voloo firmware rollback`.
If a daemon from an older host is running, finish device operations, run
`voloo daemon stop` once, then start the new one with `voloo ls`.

Validated on one board (CD-AB-0D-F3-69-BE-43-5D, macOS ARM): USB OTA 3.2 to 3.3, CLI 45/45,
MCP power/nickname, ON/cycle at about 7.4 V without a load. Not covered: rated load,
explicit rollback of this build, Windows/Linux boards, multiple devices.
